# XUI 高信噪比工程级 Token 架构与组件封装实施指南 (Token Architecture & Component Guide)

> **核心目标**：将「克制物理发丝线、高信噪比排版纪律、确定性状态机与自包含组件哲学」从设计理念直接编译为前端生产级代码架构。  
> **适用栈**：Tailwind CSS v3/v4 / CSS Variables / React / TypeScript / Vue 3。

---

## 一、 CSS Token 体系分层架构 (Three-Tier Token Pipeline)

为避免业务组件直接 hardcode 色值或出现深浅色逻辑割裂，实施标准的三层 Token 架构：

```
[ Tier 1: Primitive Tokens (基础原子) ]
             ↓ (语义抽象绑定)
[ Tier 2: Semantic System Tokens (系统语义与主题) ]
             ↓ (组件形态映射)
[ Tier 3: Component Scoped Tokens (组件级作用域变量) ]
```

### 1.1 Tier 1: 物理基色 (Primitive Palette)
在 `theme/primitives.css` 中声明不带业务语义的冷色基板与工规功能色：

```css

  --xui-slate-900: #0A0E15; /* dim 主工作区底色 */

  --xui-slate-800: #161F2E; /* container-high 悬浮卡片/弹窗 */
  --xui-slate-700: #1F2D42; /* border-bold 边框/选中 Tab */
  --xui-slate-600: #334155;
  --xui-slate-400: #94A3B8; /* 辅助冷灰文本 */
  --xui-slate-200: #E2E8F0;
```

## 二、 关键通用组件封装规范与代码模板 (Component Encapsulation)

### 2.1 基础原子：确定性输入框 (`XuiInput.tsx`)
**设计目标**：防抖动（CLS）、内联图标锚点、带清除/密码明暗切换、内置状态机（Error/Success/Focus/Disabled）。

```tsx
import React, { forwardRef, useState } from 'react';

export interface XuiInputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label?: string;
  error?: string;
  status?: 'default' | 'error' | 'success';
  prefixIcon?: React.ReactNode;
  suffixAction?: React.ReactNode;
  hint?: string;
  required?: boolean;
}

export const XuiInput = forwardRef<HTMLInputElement, XuiInputProps>(({
  label,
  error,
  status = 'default',
  prefixIcon,
  suffixAction,
  hint,
  required,
  disabled,
  className = '',
  ...props
}, ref) => {
  const currentStatus = error ? 'error' : status;

  return (
    <div className={`xui-form-item flex flex-col gap-1.5 w-full ${className}`}>
      {/* 顶部紧凑标题与提示 */}
      {(label || hint) && (
        <div className="flex items-center justify-between text-xs leading-none">
          {label && (
            <label className="font-medium text-slate-700 dark:text-slate-300 flex items-center gap-1">
              {label}
              {required && <span className="text-status-danger">*</span>}
            </label>
          )}
          {hint && <span className="font-mono text-[11px] text-slate-400 dark:text-slate-500">{hint}</span>}
        </div>
      )}

      {/* 核心输入包裹盒：单像素边框 + 状态机光环 */}
      <div
        className={`
          relative flex items-center h-8 px-2.5 rounded-sm transition-all duration-150
          bg-surface-base border
          ${currentStatus === 'error' ? 'border-status-danger ring-1 ring-status-danger/30' : ''}
          ${currentStatus === 'success' ? 'border-status-success ring-1 ring-status-success/30' : ''}
          ${currentStatus === 'default' ? 'border-border-subtle hover:border-border-strong focus-within:border-brand focus-within:ring-2 focus-within:ring-brand/20' : ''}
          ${disabled ? 'opacity-50 cursor-not-allowed bg-surface-subtle' : ''}
        `}
      >
        {prefixIcon && <span className="mr-2 text-slate-400 text-xs shrink-0">{prefixIcon}</span>}
        
        <input
          ref={ref}
          disabled={disabled}
          className="w-full h-full bg-transparent text-xs text-slate-900 dark:text-slate-100 placeholder:text-slate-400 focus:outline-none font-mono"
          {...props}
        />

        {suffixAction && <span className="ml-2 shrink-0">{suffixAction}</span>}
      </div>

      {/* 错误提示：绝对高度预留或平滑微提示，杜绝抖动 */}
      {error && (
        <div className="flex items-center gap-1 text-[11px] text-status-danger font-mono animate-fadeIn">
          <span className="w-1.5 h-1.5 rounded-full bg-status-danger shrink-0" />
          <span>{error}</span>
        </div>
      )}
    </div>
  );
});

XuiInput.displayName = 'XuiInput';
```

### 2.2 复合卡片：自包含管理员创建表单 (`XuiAdminCreateForm.tsx`)
**设计目标**：自包含逻辑、密码熵值检测、双向一致性比对、支持居中独立页/弹窗/抽屉插槽三端复用。

```tsx
import React, { useState } from 'react';
import { XuiInput } from './XuiInput';

export interface AdminFormData {
  username: string;
  password: string;
  confirmPassword: string;
}

export interface XuiAdminCreateFormProps {
  onSubmit?: (data: AdminFormData) => Promise<void> | void;
  isLoading?: boolean;
}

export const XuiAdminCreateForm: React.FC<XuiAdminCreateFormProps> = ({
  onSubmit,
  isLoading = false,
}) => {
  const [form, setForm] = useState<AdminFormData>({
    username: 'admin',
    password: '',
    confirmPassword: '',
  });
  const [errors, setErrors] = useState<Partial<Record<keyof AdminFormData, string>>>({});
  const [showPassword, setShowPassword] = useState(false);

  // 计算密码强度与熵值 (0 - 4 档)
  const calculateEntropy = (pwd: string) => {
    let score = 0;
    if (pwd.length >= 8) score++;
    if (/[A-Z]/.test(pwd) && /[a-z]/.test(pwd)) score++;
    if (/[0-9]/.test(pwd)) score++;
    if (/[^A-Za-z0-9]/.test(pwd)) score++;
    return score;
  };

  const entropyScore = calculateEntropy(form.password);
  const isMatch = form.password && form.password === form.confirmPassword;

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    const newErrors: Partial<Record<keyof AdminFormData, string>> = {};
    if (!form.username) newErrors.username = '请输入管理员用户名';
    if (!form.password) newErrors.password = '请输入新密码';
    if (form.password !== form.confirmPassword) newErrors.confirmPassword = '两次输入的密码不一致';

    setErrors(newErrors);
    if (Object.keys(newErrors).length === 0 && onSubmit) {
      onSubmit(form);
    }
  };

  return (
    <form
      onSubmit={handleSubmit}
      className="w-full max-w-[420px] p-6 rounded-md bg-surface-base border border-border-subtle shadow-sm flex flex-col gap-5"
    >
      {/* 头部区：自包含说明与权限标识 */}
      <div className="flex items-start justify-between border-b border-border-subtle pb-4">
        <div>
          <h2 className="text-sm font-semibold text-slate-900 dark:text-slate-100 flex items-center gap-2">
            创建管理员
            <span className="px-1.5 py-0.5 text-[10px] font-mono bg-brand/10 text-brand rounded-xs">
              ROOT_PROVISIONING
            </span>
          </h2>
          <p className="text-xs text-slate-500 mt-1">设置底层最高权限账号，用于管控控制台与系统调度。</p>
        </div>
      </div>

      {/* 表单字段 */}
      <div className="flex flex-col gap-4">
        <XuiInput
          label="管理员用户名"
          required
          hint="仅允许小写字母/数字"
          value={form.username}
          onChange={(e) => setForm({ ...form, username: e.target.value })}
          error={errors.username}
        />

        <div className="flex flex-col gap-1.5">
          <XuiInput
            label="新密码"
            required
            type={showPassword ? 'text' : 'password'}
            value={form.password}
            onChange={(e) => setForm({ ...form, password: e.target.value })}
            error={errors.password}
            suffixAction={
              <button
                type="button"
                tabIndex={-1}
                onClick={() => setShowPassword(!showPassword)}
                className="text-slate-400 hover:text-slate-600 dark:hover:text-slate-200 text-xs"
              >
                {showPassword ? '隐藏' : '显示'}
              </button>
            }
          />
          {/* 密码微型熵值条 (Entropy Bar) */}
          {form.password && (
            <div className="flex items-center gap-1.5 mt-0.5">
              <div className="grid grid-cols-4 gap-1 flex-1 h-1">
                {[1, 2, 3, 4].map((step) => (
                  <div
                    key={step}
                    className={`h-full rounded-xs transition-colors duration-200 ${
                      entropyScore >= step
                        ? entropyScore >= 3
                          ? 'bg-status-success'
                          : 'bg-status-warning'
                        : 'bg-surface-subtle'
                    }`}
                  />
                ))}
              </div>
              <span className="text-[10px] font-mono text-slate-400">
                {entropyScore >= 3 ? '高强度' : entropyScore >= 2 ? '中等' : '弱'}
              </span>
            </div>
          )}
        </div>

        <XuiInput
          label="确认密码"
          required
          type="password"
          value={form.confirmPassword}
          onChange={(e) => setForm({ ...form, confirmPassword: e.target.value })}
          error={errors.confirmPassword}
          status={isMatch ? 'success' : 'default'}
          hint={isMatch ? '✓ 密码完全匹配' : undefined}
        />
      </div>

      {/* 底部动作条 */}
      <div className="pt-2 flex flex-col gap-2">
        <button
          type="submit"
          disabled={isLoading}
          className="
            w-full h-8 px-4 rounded-sm font-medium text-xs text-white
            bg-brand hover:brightness-105 active:scale-[0.985]
            transition-all duration-120 flex items-center justify-center gap-1.5
            focus:outline-none focus:ring-2 focus:ring-brand/30
          "
        >
          {isLoading ? '正在配置...' : '创建管理员 →'}
        </button>
        <span className="text-center font-mono text-[10px] text-slate-400">
          创建后将直接进入控制台并自动绑定本地凭据
        </span>
      </div>
    </form>
  );
};
```

## 三、 工程化防抖与落地规则 (Implementation Rules)

1. **防视效跳动 (CLS Prevention)**：
   - 所有动态数值与时间戳强制在 CSS 根样式中加入：
     ```css
     .tabular-nums {
       font-family: var(--font-mono);
       font-variant-numeric: tabular-nums;
     }
     ```
   - 错误提示占位必须预留高度或采用内联绝对定位，杜绝因校验报错导致父容器“被撑开跳跃”。
2. **零硬编码色值 (No Hardcoded Hex)**：
   - 组件库内部样式严禁出现 `#0066FF`、`#111` 等硬编码，全部通过 `var(--border-subtle)`、`var(--surface-base)` 引用。
3. **自包含与解耦**：
   - 组件内部自包含宽度限定（如 `w-full max-w-[420px]`）与必要校验状态，脱离页面亦可独立渲染测试（Storybook / Jest）。
